# Fluxa Prospector

Complemento local do Brave/Chrome que conecta o botão de pesquisa do Fluxa ao
Google Maps. Ele abre abas em segundo plano, percorre os resultados, verifica a
ficha de cada empresa e devolve ao CRM somente negócios sem site confirmado.

## Instalação no Brave

1. Descompacte o arquivo baixado pelo Fluxa.
2. Abra `brave://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Escolha a pasta `fluxa-prospector` descompactada.
6. Recarregue o Fluxa. O status deve aparecer como **Complemento conectado**.

O complemento não usa API paga, não envia dados para terceiros além do Google
Maps já aberto no navegador e não tenta contornar CAPTCHA ou bloqueios.
